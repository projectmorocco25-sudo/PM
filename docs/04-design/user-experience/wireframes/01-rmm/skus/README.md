# RMM SKUs Wireframes

**Purpose:** This directory contains wireframes for RMM module SKU pages (list and detail pages).

**Last Updated:** 2025-12-31  
**Status:** ⚪ Not Started  
**Owner:** Emma (UI/UX + Next.js Frontend Specialist)

## Overview

This directory contains wireframes for SKU list and detail pages in the RMM module. SKUs are product-scoped and include pharmaceutical attributes (dosage_strength, dosage_form, pack_size, unit_of_measure).

## Expected Wireframes

- **Task 0.5.2.6:** SKUs list page (product-scoped, filters, pharmaceutical attributes display)
- **Task 0.5.2.7:** SKU detail page (SKU information, tabs: Overview | History, pharmaceutical attributes: dosage_strength, dosage_form, pack_size, unit_of_measure)

## Pharmaceutical Attributes

SKU wireframes must display the following pharmaceutical attributes:
- **dosage_strength:** Text input (e.g., "500mg", "10mg/ml")
- **dosage_form:** Dropdown with standard forms (Tablet, Capsule, Syrup, etc.)
- **pack_size:** Text input (e.g., "30 tablets", "100ml")
- **unit_of_measure:** Dropdown with standard units (tablets, ml, etc.)
