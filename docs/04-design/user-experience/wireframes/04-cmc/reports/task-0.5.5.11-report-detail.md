## Component Specifications

### Page Header
- **Breadcrumbs:** "Home > CMC > Reports > [Report ID]"
- **Title:** "[Report Type] - [Period]"
  - **Typography:** 24px, font-weight: 600, color: #111827
- **Actions (Right-aligned):**
  - **Download PDF Button:** Primary button (if approved)
  - **Actions Dropdown:** More actions menu
    - Options: Download Excel, Print, Share, View Audit Log

### Report Information Section
- **Layout:** Card with key-value pairs
- **Fields:**
  - **Report Type:** Report type name (Monthly, Quarterly, Annual)
  - **Period:** Report period (YYYY-MM, QX YYYY, or YYYY)
  - **Generated:** Generation date and time
  - **Generated By:** User name or "System (Automated)"
  - **Status:** Report status badge (Draft, Pending Review, Tier 2 Reviewed, Approved, Rejected)
  - **Approved By:** User name and role (if approved, e.g., "Fatima Al-Mansouri (Tier 1)")
  - **Approved:** Approval date (if approved)
  - **View Audit Log Link:** Link to audit log for this report
- **Styling:**
  - **Labels:** 14px, color: #6b7280, font-weight: 500
  - **Values:** 16px, color: #111827
  - **Status Badge:** Color-coded based on status

### Tabs Navigation
- **Tabs:**
  1. **PDF View:** Full PDF report viewer
  2. **Data Tables:** Interactive data tables with export
  3. **Charts:** Interactive charts and visualizations
  4. **Summary:** Executive summary and key metrics
- **Styling:** Standard tab navigation with active state indicator

### PDF View Tab Content
- **PDF Viewer:**
  - **Layout:** Embedded PDF viewer
  - **Features:**
    - **Zoom Controls:** Zoom in/out buttons
    - **Page Navigation:** Previous/Next page buttons
    - **Page Counter:** "Page X of Y" display
    - **Fullscreen:** Fullscreen button
    - **Scroll:** Scrollable PDF content
  - **Styling:** PDF viewer with controls toolbar
- **Actions:**
  - **Download PDF:** Download full PDF report
  - **Print:** Print PDF report
  - **Share:** Share report link or file

### Data Tables Tab Content
- **Score Distribution Table:**
  - **Layout:** Scrollable table
  - **Columns:**
    1. **Score Range:** Score range (90-100, 80-89, 70-79, 60-69, <60)
    2. **Company Count:** Number of companies in range
    3. **Percentage:** Percentage of total companies
  - **Features:**
    - **Export CSV:** Export table data as CSV
    - **Export Excel:** Export table data as Excel
    - **Sortable:** Click column header to sort
  - **Styling:** Table with borders, alternating row colors
- **Company Scores Table:**
  - **Layout:** Scrollable table
  - **Columns:**
    1. **Company:** Company name
    2. **Score:** Total score (out of 100)
    3. **Trend:** Score change vs previous period (↑/↓ with amount)
    4. **Rank:** Company rank
  - **Features:**
    - **Export CSV:** Export table data as CSV
    - **Export Excel:** Export table data as Excel
    - **Sortable:** Click column header to sort
    - **Pagination:** Paginated table (20 rows per page)
  - **Styling:** Table with borders, alternating row colors

### Charts Tab Content
- **Score Distribution Chart:**
  - **Layout:** Bar chart visualization
  - **Content:**
    - Horizontal bar chart showing score ranges
    - Company counts for each range
    - Percentage indicators
  - **Styling:** Color-coded bars (green for high scores, red for low scores)
  - **Interactive:** Tooltips showing exact values on hover
- **Score Trends Chart:**
  - **Layout:** Line chart visualization
  - **Content:**
    - Line chart showing average score over time
    - X-axis: Months (Jul, Aug, Sep, Oct, Nov, Dec)
    - Y-axis: Score (0-100)
  - **Styling:** Line chart with grid lines
  - **Interactive:** Tooltips showing exact values on hover
- **Actions:**
  - **Export Chart:** Export chart as image (PNG, SVG)
  - **Download Image:** Download chart image
- **Styling:** Charts with legends and labels

### Summary Tab Content
- **Executive Summary Section:**
  - **Layout:** Card with summary information
  - **Key Metrics:**
    - Total Companies
    - Average Score
    - Score Trend (vs previous period)
    - Companies Below 60 (count and percentage)
    - Active Disputes
  - **Highlights:**
    - Key findings and insights
    - Trend analysis
    - Notable changes
  - **Styling:** Summary card with structured data display

### Action Buttons (MOH Only)
- **Review Report Button:**
  - **Role:** Tier 2 only (if not yet reviewed)
  - **Action:** Opens report review interface
  - **Styling:** Primary button
- **Approve Report Button:**
  - **Role:** Tier 1 only (if Tier 2 reviewed)
  - **Action:** Approves report for release
  - **Styling:** Primary button
- **Reject Button:**
  - **Role:** Tier 1 only (if Tier 2 reviewed)
  - **Action:** Rejects report with reason
  - **Styling:** Secondary button

### Download/Export Actions
- **Download PDF:** Download full PDF report (if approved)
- **Download Excel:** Download data tables as Excel (if approved)
- **Print:** Print PDF report
- **Share:** Share report link or file

## Role-Based Access

### Company Users
- **View:** Cannot access reports (MOH only)
- **Access:** Redirected or shown "Access Denied" message

### MOH Tier 1
- **View:** All reports with full access
- **All Tabs:** Full access to PDF view, data tables, charts, summary
- **Actions:**
  - View Report Details
  - Approve/Reject Reports
  - Download Reports (if approved)
  - Export Data
  - View Audit Log
- **Data:**
  - Can see all report information, data, charts
  - Can approve reports for release

### MOH Tier 2
- **View:** All reports with full access
- **All Tabs:** Full access to PDF view, data tables, charts, summary
- **Actions:**
  - View Report Details
  - Review Reports (read-only)
  - Download Reports (if approved)
  - Export Data
  - View Audit Log
- **Data:**
  - Can see all report information, data, charts
  - Can review reports but cannot approve (Tier 1 only)

## State Variations

### Loading State
- **Skeleton Loaders:** PDF viewer, tables, charts with skeleton placeholders
- **Tabs:** Skeleton tab content

### Error State
- **Message:** "Unable to load report"
- **Subtext:** Error message details
- **Action Button:** "Retry"

### Draft State
- **Status:** "Draft"
- **Actions:** Download/Print disabled (report not finalized)
- **Note:** "Report is in draft status and cannot be downloaded"

### Pending Review State
- **Status:** "Pending Review"
- **Actions:** Download/Print disabled (report not approved)
- **Note:** "Report is pending review and cannot be downloaded"

### Approved State
- **Status:** "Approved"
- **Actions:** All download/print actions enabled
- **Note:** "Report has been approved and can be downloaded"

### Rejected State
- **Status:** "Rejected"
- **Actions:** Download/Print disabled (report rejected)
- **Note:** "Report has been rejected and cannot be downloaded"
- **Rejection Reason:** Displayed in report information section

### Module Inactive State
- **Message:** "CMC module is not active"
- **Subtext:** "Contact MOH Tier 1 to activate the CMC module"
- **Visual:** Inactive module indicator
- **Note:** Historical data may still be accessible if `has_historical_cmc_data()` returns true

## Business Rules

1. **Module Status:** CMC is optional (license-controlled)
2. **Module Activation Check:** Routes check `is_module_active('cmc')` for active module, or `has_historical_cmc_data()` for historical data access
3. **Report Generation:** Reports generated automatically (monthly, quarterly, annually) or manually (custom reports)
4. **Status Workflow:** Draft → Pending Review → Tier 2 Reviewed → Approved/Rejected
5. **Role-Based Access:**
   - Companies cannot access reports (MOH only)
   - MOH Tier 1 can view, approve, and download all reports
   - MOH Tier 2 can view, review, and download approved reports
6. **Download Access:** Only approved reports can be downloaded
7. **Export Options:** Data tables can be exported as CSV or Excel
8. **Chart Export:** Charts can be exported as PNG or SVG
9. **PDF View:** Full PDF report visible in embedded viewer
10. **Print:** PDF reports can be printed directly from viewer
11. **Share:** Reports can be shared via link or file download
12. **Audit Log:** All report actions logged in audit trail
13. **Status Badges:** Color-coded based on status (gray, yellow, blue, green, red)
14. **Data Tables:** Interactive tables with sorting and pagination
15. **Charts:** Interactive charts with tooltips and export options
