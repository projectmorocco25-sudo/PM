## Component Specifications

### Page/Modal Header
- **Title:** "Review Compliance Report" (Tier 2) or "Approve Compliance Report" (Tier 1)
  - **Typography:** 20px, font-weight: 600, color: #111827
- **Report Context:**
  - **Report ID:** "REP-2025-001"
  - **Report Type:** "Monthly Compliance Report"
  - **Period:** "December 2024"
  - **Typography:** 14px, color: #6b7280
- **Close Button:** X button (top-right corner, if modal)

### Tier 2 Review Interface

#### Report Information Section
- **Layout:** Card with key-value pairs
- **Fields:**
  - **Type:** Report type (Monthly, Quarterly, Annual)
  - **Period:** Report period (YYYY-MM, QX YYYY, or YYYY)
  - **Generated:** Generation date and time
  - **Generated By:** User name or "System (Automated)"
  - **Status:** Report status badge (Draft, Pending Review)
- **Styling:** Read-only text with light background

#### Report Summary Section
- **Layout:** Card with summary information
- **Key Metrics:**
  - Total Companies
  - Average Score
  - Score Trend (vs previous period)
  - Companies Below 60 (count and percentage)
  - Active Disputes
- **Styling:** Summary card with structured data display

#### Review Checklist Section
- **Layout:** Checklist with checkboxes
- **Items:**
  1. **Data Completeness:** All required data included
  2. **Data Accuracy:** Data verified against source
  3. **Calculations Verified:** All calculations verified
  4. **Charts and Visualizations:** Charts display correctly
  5. **Summary Accuracy:** Executive summary accurate
- **Features:**
  - **Checkboxes:** Check/uncheck items
  - **Validation:** All items must be checked before approval recommendation
- **Styling:** Checklist with checkboxes and labels

#### Review Notes (Required)
- **Label:** "Review Notes *"
- **Type:** Text area
- **Placeholder:** "Provide detailed review notes..."
- **Character Limit:** 1000 characters
- **Character Count:** Display "X/1000" characters remaining
- **Validation:**
  - Required field
  - Minimum 50 characters
  - Maximum 1000 characters
- **Styling:** Multi-line text area with character counter

#### Recommendation Selection (Required)
- **Label:** "Recommendation"
- **Type:** Radio button group
- **Options:**
  1. **Report Complete - Recommend approval:** Recommends approving report
  2. **Report Incomplete - Request revision:** Recommends rejecting report
- **Default:** First option (Complete)
- **Styling:** Radio buttons with labels
- **Validation:** Required field

#### Submit Review Button
- **Action:** Submits review and forwards to Tier 1
- **Disabled State:** Disabled if form is invalid or checklist incomplete
- **Styling:** Primary button

### Tier 1 Approval Interface

#### Report Information Section
- **Layout:** Same as Tier 2
- **Content:** Same report information displayed

#### Tier 2 Review Notes Section
- **Layout:** Card with Tier 2 review information
- **Content:**
  - **Reviewed By:** User name and role (e.g., "Ahmed Benali (Tier 2)")
  - **Reviewed Date:** Review timestamp
  - **Review Notes:** Full text of Tier 2 review notes
  - **Recommendation:** Tier 2 recommendation
- **Styling:** Read-only text with light background

#### Report Summary Section
- **Layout:** Same as Tier 2
- **Content:** Same summary information displayed

#### Review Checklist Section
- **Layout:** Same as Tier 2 (read-only)
- **Content:** Same checklist items displayed (checked/unchecked status)
- **Styling:** Read-only checklist display

#### Approval Decision (Required)
- **Label:** "Approval Decision *"
- **Type:** Radio button group
- **Options:**
  1. **Approve Report - Release for download:** Approves report and releases for download
  2. **Reject Report - Request revision:** Rejects report and requests revision
- **Default:** Based on Tier 2 recommendation
- **Styling:** Radio buttons with labels
- **Validation:** Required field

#### Approval Notes (Conditional)
- **Label:** "Approval Notes"
- **Type:** Text area
- **Visibility:** Only shown if "Approve Report" selected
- **Placeholder:** "Provide approval notes (optional)..."
- **Character Limit:** 500 characters
- **Character Count:** Display "X/500" characters remaining
- **Help Text:** "Optional: Provide approval notes"
- **Validation:**
  - Optional field
  - Maximum 500 characters
- **Styling:** Multi-line text area with character counter

#### Rejection Reason (Conditional)
- **Label:** "Rejection Reason *"
- **Type:** Text area
- **Visibility:** Only shown if "Reject Report" selected
- **Placeholder:** "Provide detailed rejection reason..."
- **Character Limit:** 1000 characters
- **Character Count:** Display "X/1000" characters remaining
- **Help Text:** "Required: Explain why report is rejected"
- **Validation:**
  - Required if reject selected
  - Minimum 50 characters
  - Maximum 1000 characters
- **Styling:** Multi-line text area with character counter

#### Approve Report Button
- **Action:** Submits approval and releases report
- **Disabled State:** Disabled if form is invalid
- **Styling:** Primary button

## Role-Based Access

### MOH Tier 2
- **Access:** Can review reports (cannot approve)
- **Actions:**
  - View report information
  - Review report summary
  - Complete review checklist
  - Provide review notes
  - Make recommendation
  - Submit review
- **Workflow:** Review → Recommend → Forward to Tier 1

### MOH Tier 1
- **Access:** Can approve reports (after Tier 2 review)
- **Actions:**
  - View report information
  - View Tier 2 review notes
  - Review report summary
  - Review checklist (read-only)
  - Make approval decision
  - Provide approval notes (if approve) or rejection reason (if reject)
  - Approve/Reject report
- **Workflow:** Review Tier 2 notes → Decide → Approve/Reject

### Company Users
- **Access:** Cannot review or approve reports (view only)
- **View:** Cannot access reports (MOH only)

## State Variations

### Empty State (Initial)
- **Form:** All fields empty
- **Submit Button:** Disabled
- **Character Count:** "0/1000" or "0/500"
- **Checklist:** All items unchecked (Tier 2)

### Valid State
- **Form:** All required fields filled
- **Submit Button:** Enabled (if checklist complete for Tier 2)
- **Character Count:** "X/1000" or "X/500" (within limit)
- **Checklist:** All items checked (Tier 2)
- **Recommendation/Decision:** Selected

### Invalid State
- **Form:** Required fields missing or invalid
- **Submit Button:** Disabled
- **Error Messages:** Display validation errors
- **Field Highlighting:** Invalid fields highlighted in red
- **Checklist:** Not all items checked (Tier 2)

### Loading State (Submitting)
- **Form:** Disabled (cannot edit)
- **Submit Button:** Loading spinner, "Submitting Review..." or "Approving Report..."
- **Cancel Button:** Disabled

### Success State
- **Message:** "Review submitted successfully" or "Report approved successfully"
- **Action:** Closes modal/page and refreshes report detail
- **Notification:** Success notification shown
- **Follow-up:** Report status updated (Tier 2 Reviewed or Approved)

### Error State
- **Message:** "Unable to submit review" or "Unable to approve report"
- **Subtext:** Error message details
- **Action Button:** "Retry"
- **Form:** Re-enabled for editing

### Approve Report State (Tier 1)
- **Approval Decision:** "Approve Report" selected
- **Approval Notes:** Shown (optional)
- **Rejection Reason:** Hidden

### Reject Report State (Tier 1)
- **Approval Decision:** "Reject Report" selected
- **Approval Notes:** Hidden
- **Rejection Reason:** Shown and required

## Business Rules

1. **Role Access:**
   - Only MOH Tier 2 can review reports
   - Only MOH Tier 1 can approve reports
2. **Workflow:** Draft → Pending Review → Tier 2 Reviewed → Approved/Rejected
3. **Review Required:** Tier 2 must review before Tier 1 can approve
4. **Required Fields (Tier 2):**
   - Review Checklist (all items checked)
   - Review Notes (minimum 50 characters)
   - Recommendation
5. **Required Fields (Tier 1 - Approve):**
   - Approval Decision
   - Approval Notes (optional, maximum 500 characters)
6. **Required Fields (Tier 1 - Reject):**
   - Approval Decision
   - Rejection Reason (minimum 50 characters)
7. **Character Limits:**
   - Review Notes: 1000 characters
   - Approval Notes: 500 characters
   - Rejection Reason: 1000 characters
8. **Checklist Validation:** All checklist items must be checked before approval recommendation (Tier 2)
9. **Report Release:** Only approved reports can be downloaded
10. **Notification:**
    - System notified when report is reviewed
    - System notified when report is approved/rejected
11. **Audit Log:** All review and approval actions logged in audit trail
12. **Status Update:** Report status updated after review/approval
13. **Multiple Reviews:** Can review/approve only once (status prevents duplicate actions)
14. **Revision Workflow:** If rejected, report returns to draft status for revision
