**API verification (1.1.1.18c):**
- **`shared_update_user_profile(p_full_name, p_avatar_url, p_timezone, p_language text)`** — All optional (DEFAULT NULL). Returns `{ success, user? }` or `{ success: false, error }`. Updates own row via `auth.uid()`; coalesce keeps existing values for null params. GRANT to `authenticated`, `service_role`. Migration: `20260127150900_rpc_shared_functions.sql`.
- **`shared_update_user_preferences(p_preferences jsonb)`** — Updates `users.notification_preferences`. Returns `{ success }` or `{ success: false, error }`. GRANT to `authenticated`, `service_role`.
- **`shared_get_user_permissions(user_id)`** — Used for role/company_id. **`rmm_get_company(p_id)`** — Used for company name. **Supabase Auth:** `updateUser({ password })`, `signInWithPassword` for password change. **Storage:** `avatars` bucket (migration `20260127151600_storage_avatars_bucket.sql`).
