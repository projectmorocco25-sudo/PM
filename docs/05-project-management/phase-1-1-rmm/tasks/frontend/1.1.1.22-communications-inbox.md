**API verification:**
- **communications_list_conversations(p_archived boolean DEFAULT false):** Returns `{ data: [...] }`. Each item: id, type, subject, company_id, created_by, created_at, updated_at, is_announcement, archived_at. Excludes announcements; RLS applies. No filters, search, or pagination params.
- **communications_get_conversation(p_conversation_id uuid):** Returns `{ conversation, messages }` or `{ error, id }`. conversation: id, type, subject, company_id, created_by, created_at, updated_at, is_announcement, archived_at. messages: id, conversation_id, sender_id, recipient_id, content, is_system_message, delivered_at, created_at. Does not return workflow_entity_*, lifecycle_state, or read receipts.
- **communications_send_message(p_conversation_id uuid, p_content text, p_recipient_id uuid DEFAULT NULL):** Returns `{ success, id? }` or `{ success: false, error }`. Empty content → `content_required`. No attachment support.
- **communications_archive_conversation(p_conversation_id uuid):** MOH-only (RLS). Returns `{ success }` or `{ success: false, error: 'not_found_or_forbidden' }`.
