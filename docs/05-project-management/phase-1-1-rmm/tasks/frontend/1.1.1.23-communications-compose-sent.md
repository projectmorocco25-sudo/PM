**Key requirements (wireframes read in full, no truncation):**

**Compose (task-0.5.1.26):**
- **Route:** `/communications/compose`. Breadcrumbs: Home > Communications > Compose. Title: "Compose New Message".
- **To***: Search recipients, selected chips (remove via X), filters Role / Company. Required.
- **Subject***: Single-line, "Enter subject...", required, max length.
- **Message***: Textarea "Type your message...", min 200px max 500px, required.
- **Attachments (optional):** Attach Files, drag-drop, file list with remove; limits (e.g. 10MB, 5 files, PDF/DOC/etc.).
- **Link to Workflow Entity (optional):** Entity type dropdown, entity search/select; immutability warning when selected.
- **Lifecycle info box:** Created → Sent → Delivered → Read; workflow-linked note; 7-year retention.
- **Actions:** Cancel, Send (primary; disabled if required empty; loading spinner), Save Draft.
- **Validation:** Required To/Subject/Message; recipient, file size/type, max files, subject length.
- **States:** Sending (disable form, spinner), success (notify, navigate to sent), draft saved, file upload progress.

**Sent (task-0.5.1.27):**
- **Route:** `/communications/sent`. Breadcrumbs: Home > Communications > Sent Messages. Title: "Sent Messages". Actions: Filters ▼, Search.
- **List:** To, Subject, Preview (2 lines), status (✓ Sent / ✓✓ Delivered / ✓✓ Read), timestamp. Click → conversation detail. Workflow-linked: regulatory link.
- **Filters:** Date (7d/30d/custom), Recipient, Status (Sent/Delivered/Read), Entity type.
- **Empty:** "No sent messages", [Compose Message]. Load More.

**Implementation Summary:**

- **Compose (`/communications/compose`):** `ComposeContent.tsx` — breadcrumbs (Home > Communications > Compose), title "Compose New Message". To*: Company users see "MOH" (fixed); MOH users get company dropdown from `rmm_list_companies` plus "None". Subject*, Type (workflow_related/message/announcement), Message*. Lifecycle info box (Created→Sent→Delivered→Read, 7-year retention). Cancel → inbox, Save Draft (localStorage), Send → `communications_create_conversation` then redirect to `/communications/sent`. Validation: To + Subject + Message required; subject max 200. Loading state on send. Wireframe binding in `page.tsx` and `ComposeContent.tsx`.
- **Sent (`/communications/sent`):** `SentContent.tsx` — breadcrumbs (Home > Communications > Sent Messages), title, Filters toggle, Search. List from `communications_list_sent`; each item: Subject, To (company_id truncation), Preview (subject fallback), "✓ Sent", timestamp. Click → `/communications/inbox/[id]`. Filters (Type, Date), client-side search. Loading, empty, error states. [Compose Message] in empty state. Wireframe binding in `page.tsx` and `SentContent.tsx`.
- **Hooks:** `useCreateConversation`, `useSentList` in `hooks/use-communications.ts`. All use hosted Supabase only.

**Deviations:**

- **Workflow entity linking:** Not implemented. `communications_create_conversation` has no workflow_entity_type / workflow_entity_id params.
- **Attachments:** Not implemented. No attachment support in create RPC.
- **To:** Wireframe has multi-recipient search/chips. Implemented as single "To": company users → "MOH"; MOH → company dropdown (or None). No user/recipient search; RLS prevents company users from listing users.
- **Recipient display on Sent:** List RPC returns no recipient names. "To" shown as truncated company_id.
- **Preview:** List RPC has no last-message preview. Subject used as fallback.
- **Status (✓✓ Delivered / ✓✓ Read):** List RPC has no status. All items show "✓ Sent".
