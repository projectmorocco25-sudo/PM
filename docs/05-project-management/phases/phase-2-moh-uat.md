# Phase 2: MOH UAT with Mock Data

**Phase:** Phase 2 - MOH UAT with Mock Data  
**Duration:** 1 month (Month 7)  
**Status:** Not Started  
**Prerequisites:** Phase 1.4 (Holistic MVP Testing) complete

## Objective

MOH validation of system functionality with mock data, gathering feedback and obtaining sign-off before real company pilot.

## Scope

### UAT Activities
- MOH Tier 1 and Tier 2 Officers test with mock data
- Validate workflows, approvals, governance
- Gather feedback on UI/UX and functionality
- Incorporate feedback
- Sign-off on functionality

## Deliverables

1. MOH UAT sign-off
2. Feedback incorporated
3. System ready for real company pilot

## Success Criteria

- All workflows validated by MOH
- Governance requirements confirmed
- MOH sign-off received
- System ready for real data
