## Testing Strategy

### Test Types

1. **Unit Tests:** Component and function-level testing
2. **Integration Tests:** API and database integration testing
3. **RLS Tests:** Row-Level Security policy verification
4. **E2E Tests:** End-to-end user journey testing
5. **Workflow Tests:** State machine and workflow testing

### Test Coverage Areas

- Authentication and authorisation
- RLS policy enforcement
- Workflow state transitions
- Audit logging integrity
- API endpoint validation
