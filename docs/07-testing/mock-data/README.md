# Mock Data

**Purpose:** This directory contains mock data strategy, specifications, and generation scripts documentation for the PM platform.

**Last Updated:** 2025-12-31

## Overview

The PM platform uses comprehensive mock data (75 companies) for development, testing, and customer presentations. This directory documents the mock data strategy, specifications, and generation approach.

## Mock Data Strategy

- **75 Mock Companies:** 15 IPCs + 60 Wholesalers with diverse profiles
- **Historical Data:** 2-3 years of historical data (AAMS, MSQ, WSL, exports, compliance)
- **Usage:** Development, testing, customer MVP presentation, and MOH UAT
- **Benefits:** Zero risk to real companies, comprehensive testing coverage, realistic demonstrations

## Expected Content

- **Mock Data Specification:** Detailed specification of mock data structure and requirements
- **Data Generation Strategy:** Approach for generating realistic mock data
- **Data Profiles:** Profiles for different company types and scenarios
- **Historical Data Strategy:** Approach for generating 2-3 years of historical data
