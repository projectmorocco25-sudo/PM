# Training Materials

**Purpose:** This directory contains training materials, presentations, and resources for user training.

**Last Updated:** 2025-12-31

## Overview

Training materials support user onboarding and ongoing education for all user roles in the PM platform. Materials are organized by user role and training topic.

## Directory Structure

Training materials will be organized by:
- **User Role:** Company Admin, Company Manager, Company User, MOH Tier 1, MOH Tier 2 Officer, MOH Tier 2 Registrar, Auditor
- **Module:** RMM, VCI, ECS, CMC
- **Topic:** Specific features and workflows

## Expected Content

- **Training Presentations:** Slide decks for training sessions
- **Video Tutorials:** Video guides for common tasks
- **Quick Reference Guides:** One-page reference guides
- **Hands-On Exercises:** Practice exercises for training sessions
- **FAQ Documents:** Frequently asked questions by role
