# User Manuals

**Purpose:** This directory contains comprehensive user manuals organized by user role.

**Last Updated:** 2025-12-31

## Overview

User manuals provide detailed documentation for end users, organized by role. Each manual covers all features and workflows relevant to that user role.

## Directory Structure

User manuals will be organized by user role:
- **Company Admin Manual:** Complete guide for Company Admin users
- **Company Manager Manual:** Complete guide for Company Manager users
- **Company User Manual:** Complete guide for Company User users
- **MOH Tier 1 Manual:** Complete guide for MOH DMP Tier 1 users
- **MOH Tier 2 Officer Manual:** Complete guide for MOH DMP Tier 2 Officer users
- **MOH Tier 2 Registrar Manual:** Complete guide for MOH DMP Tier 2 Registrar users
- **Auditor Manual:** Complete guide for Auditor users

## Expected Content

Each user manual should include:
- Role overview and capabilities
- Getting started guide
- Feature documentation (organized by module)
- Workflow guides with step-by-step instructions
- Screenshots and examples
- Troubleshooting section
- FAQ section
