# Documentation Archive

**Purpose:** Archived and deprecated documentation

---

## Archive Policy

Documents are moved here when:

1. **Superseded:** Replaced by newer versions
2. **Deprecated:** No longer applicable to current project state
3. **Historical:** Retained for reference but not actively maintained
4. **Completed:** One-time documents (plans, audits) after completion

---

## Archive Structure

Documents should be organised by original location or topic:

```
archive/
├── requirements/      # Archived requirements docs
├── architecture/      # Archived architecture docs
├── design/           # Archived design docs
├── project-management/ # Archived PM docs
└── misc/             # Other archived documents
```

---

## Retrieval

Archived documents remain accessible for historical reference. If a document needs to be restored to active status, move it back to its original location.
